# 7. Reverse Integer


**Difficulty:** Medium

## Problem

Given a signed 32-bit integer `x`, return `x` with its digits reversed.

If reversing `x` causes the value to go outside the signed 32-bit integer range `[-2³¹, 2³¹ - 1]`, return `0`.

> **Note:** Assume the environment does not allow you to store 64-bit integers (signed or unsigned).

## Examples

| Input | Output |
|---|---|
| `123` | `321` |
| `-123` | `-321` |
| `120` | `21` |

## Constraints

- `-2³¹ <= x <= 2³¹ - 1`
